# BI-аналитика
 В репозитории размещены практические работы по построению дашбордов и анализу продуктовых метрик, а также SQL-запросы для построения графиков, выполненные в рамках прохождения курса "Симулятор Аналитика" от Karpov.Courses

### Задание 1
Главный вопрос, на который должна отвечать аналитика на самом начальном этапе — это вопрос «сколько?». На практике это означает, что если нам поручили настроить аналитику продукта, нужно начать с базовых дашбордов, которые покрывают собой ключевые аудиторные метрики и ключевые события нашего продукта. В лекции мы заложили основу дашбордов по ленте новостей, ваша задача теперь доделать эти дашборды. Подумайте, какие еще графики, срезы, метрики имеет смысл добавить на дашборды.
В качестве решения этого задания вам нужно сделать: Основной дашборд по ленте новостей с метриками прошлое время.

### Задание 2
Вашей задачей будет составить дашборд, который описывает взаимодействие двух сервисов — ленты и сообщений. 
Постарайтесь при помощи дашборда ответить на следующие вопросы:
1. Какая у нашего приложения активная аудитория по дням, т.е. пользователи, которые пользуются одновременно и лентой новостей, и сервисом сообщений. 
2. Сколько пользователей использует только ленту новостей и не пользуются сообщениями.   
Какие еще вопросы вы бы хотели исследовать о связи двух продуктов? Добавляйте графики и описания таких вопросов к себе на дашборд.
